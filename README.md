## 📖 Overview

Finding cohesive color combinations for hijabi outfits—balancing the **Hijab/Scarf**, **Top/Shirt**, and **Bottom/Pants**—can be challenging. **PaduPadan for Hijabi** eliminates color guesswork by using scientific color space evaluations ($\Delta E$ in CIELAB) to score outfit harmony, detect saturation clashes, suggest instant palette quick-fixes, and allow seamless wardrobe archiving.

## 🌟 Key Features

- **🧍‍♀️ Interactive 3-Layer Mannequin Preview:** Real-time visual mannequin rendering that updates immediately as you swap colors for Hijab, Top, and Pants.
- **🎨 CIEDE2000 Color Harmony Engine:** Evaluates color distance ($\Delta E$), lightness contrast, saturation penalties, and neutral balancing to generate an objective **Match Score (0–100%)** and style classification (*Soft Pastel, Warm Earth Tone, Cewek Mamba, Monochrome Casual, Tone-on-Tone, etc.*).
- **📸 Photo Color Scanner (Eyedropper):** Upload clothing photos from your camera or gallery, tap any fabric spot to sample its exact HEX color using HTML5 Canvas, and apply it directly to your outfit.
- **✨ 1-Tap Quick Fixes & Smart Randomizer ("Surprise"):** Receive algorithmic single-color swap recommendations to instantly elevate low-scoring outfits, or use the smart randomizer to discover high-harmony combinations.
- **👗 Digital Wardrobe & Tagging:** Save favorite outfits, organize them with occasion tags (*Hangout, Work/Class, Formal, Casual*), filter, sort by score/date, and perform bulk management.
- **🛠️ Custom Slot Palettes & Defaults:** Customize color palettes for individual clothing slots and save personalized default outfit setups.
- **☁️ Hybrid Cloud Sync & Offline Fallback:** Works 100% offline using browser `localStorage`, or syncs seamlessly across devices when signed in via **Supabase Auth** and PostgreSQL database.
- **🌐 Multilingual & Dynamic Theme:** Full **English** & **Indonesian** (i18n) translation support, paired with Light, Dark, and System Auto Theme modes.

## 🔄 How It Works

1. **Mix & Select Colors:** Pick colors for your Hijab, Top, and Pants using preset palettes, custom color pickers, or the photo scanner.
2. **Review Match Score:** Check your 0–100% score, style vibe tag, and color breakdown advice generated by the CIEDE2000 algorithm.
3. **Apply Quick Fixes:** Tap suggested color swaps to resolve saturation or contrast clashes in seconds.
4. **Save to Wardrobe:** Tag your outfit (*Hangout, Work, Formal, Casual*) and store it locally or sync it to your account.

## 🔬 Color Matching Engine

The application evaluates color combinations through a multi-stage color science pipeline:

- **CIELAB ($\Delta E$) Distance:** Measures perceptual color differences between clothing pairs.
- **Weighted Slot Pairs:** Applies weighted visual importance (Top-Pants: 50%, Hijab-Top: 35%, Hijab-Pants: 15%).
- **Saturation Penalty ($P_{sat}$):** Penalizes overly saturated non-neutral combinations ($S > 65\%$).
- **Hue Clash Penalty ($P_{clash}$):** Identifies non-neutral color wheel clashes ($70^\circ - 110^\circ$ hue distance) without a neutral balancing color.
- **Neutral Color Bonus:** Rewards balanced uses of neutral tones (cream, black, white, denim, earth neutrals).

## 🛠️ Tech Stack

---

## 🗄️ Database & Storage Architecture

**PaduPadan for Hijabi** follows an **Offline-First / Hybrid Architecture**:
- **Offline / Unauthenticated:** All outfits, default color preferences, and custom slot palettes are stored locally in `localStorage`.
- **Authenticated (Supabase):** Local wardrobe items are automatically migrated to your cloud profile upon login, syncing user defaults, saved outfits, and custom slot palettes securely across all your devices.
